Privacy Policy

Last updated: November 12, 2026

Shortly Uploader ("the tool") is a private tool used only by the owner of the YouTube channel Shortly to upload his own videos.

YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. YouTube data is also handled under the Google Privacy Policy (https://policies.google.com/privacy).

What information we access

The tool only requests the Google OAuth permission https://www.googleapis.com/auth/youtube.upload for the owner's own Google account. It uses it to upload the owner's video files and their title, description, tags, thumbnail and scheduled publish time (YouTube API methods videos.insert and thumbnails.set). It does not read, collect, store or share any YouTube data or personal information of other users.

How information is used, stored and shared

The OAuth token is stored only on the owner's computer and is used only to upload the owner's videos. No data is sold, shared with third parties or used for advertising. The tool does not use cookies or tracking.

Deletion and revoking access

You can revoke the tool's access at any time from the Google security settings page: https://myaccount.google.com/permissions. When access is revoked, or on request by email, the stored token is deleted from the owner's computer within 7 days. The tool keeps no other user data.
